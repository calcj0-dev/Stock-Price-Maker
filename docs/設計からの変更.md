## 2. 画面の変更

### 2.1 セリの画面（S3）：左右の列 → 値段のはしご
- 真ん中に**縦の値段の目盛り**（5日とも同じ 500〜1,600円）。人は**自分の希望額の高さ**に置く（板寄せの板に近い形）
- 値段は**横線を指で上下に動かして**決める（つまみはなし）。±10円のボタンは残す
- 線より上の買いたい人・線より下の売りたい人が光る。光る側に色の帯
- 人の横は数字だけ（「○円までなら買う」の吹き出しはなし）
- 人は**顔**で描く：光った人は笑顔、光っていない人は困り顔、組めなかった人は真顔（文字を増やさずに気持ちを見せる）
- 上に目標の一言「**売買取引できる組を、一番多くしよう**」
- 2日目から、人が**前の日の位置から動いて**始まる。**来た人はふわっと現れ、帰った人は消える**（ニュースが行列を動かすことを見せる）
- 同じ側の人どうしの希望額は **40円以上あける**（読み込み時に検査）。片側は1〜14人

→ 設計 2章の S3 の図、5.7（タッチ操作）、要件 3.1 P3（操作）・P4（画面）、要件 4章 U4

### 2.1b 人の絵と値付け師（2026-11-20 オーナー案）
- 盤の人は**立体の胸像**（SVG で影と光を付ける。画像生成は使わない）。光ると手を挙げて笑顔、光っていないと腕を組んで困り顔、組めなかった人は真顔で薄く
- 同じ値段の人は横に並ぶ（段）。段が近いときは人を自動で小さくする（小さいスマホで重ならない）
- 右端に**値付け師**（全身・赤いはちまき）。値段の線の端を持ち、上げている間は引き上げる・下げている間は押し下げる・止まると支える
- タイトルの絵と URL のカード画像も、この人と値付け師にそろえた

### 2.2 答え合わせ（S4）
- 決めたら、**組になった買いたい人と売りたい人が1組ずつ真ん中に出てきて握手**し、「1組、2組…」と数え上げる（触ると飛ばせる）。終わると組は直線で残る。相手がいなかった人は真顔で薄くなる。答え合わせの文は数え終わってから出る
- 正解の値段を**青の点線**で重ねる
- 文は今まで通り（評価・成立 ○組・つり合いの値段・仕組みの一言）。仕組みの一言（2〜5日目）は、人数の変化が分かる文に直した

→ 設計 1.5、`ja.json` の `reasons` は直し済み

### 2.2b ニュースの画面（S2。2026-11-20）
- 見出しの下に「**これまでの株価**」の小さなチャート：昨日までの株価（つり合いの値段）を青い線でつなぎ、今日の所は「？」。縦の目盛りは毎日同じ 900〜1,200円。2日目からは下に「昨日の株価 ○円」
- 「上がる？下がる？」の予想は入れない（決定 P3 のまま）

### 2.3 結果画面（S5）
- 日ごとの一言は1行（「1日目：安すぎ（6組／最大 7組）」）と「**正解を見る**」ボタン。押すと、その日の盤で正解の値段の組と、自分の値段（黒の点線）と仕組みの一言を見られる
- シェアのボタンは点数と称号のすぐ下

→ 設計 1.7・2章の S5 の図

### 2.3b タイトルに戻る（2026-11-20 オーナー）
- ニュース・セリ・チュートリアル・結果の左上に「‹ タイトル」。右上は音のボタン
