## 2. 画面の変更

### 2.1 セリの画面（S3）：左右の列 → 値段のはしご
- 真ん中に**縦の値段の目盛り**（5日とも同じ 500〜1,600円）。人は**自分の希望額の高さ**に置く（板寄せの板に近い形）
- 値段は**横線を指で上下に動かして**決める（つまみはなし）。±10円のボタンは残す
- 線より上の買いたい人・線より下の売りたい人が光る。光る側に色の帯
- 人の横は数字だけ（「○円までなら買う」の吹き出しはなし）
- 人は**顔**で描く：光った人は笑顔、光っていない人は困り顔、組めなかった人は真顔（文字を増やさずに気持ちを見せる）
- 上に目標の一言「**売買取引できる組を、一番多くしよう**」
- 2日目から、人が**前の日の位置から動いて**始まる。**来た人はふわっと現れ、帰った人は消える**（ニュースが行列を動かすことを見せる）
- 同じ側の人どうしの希望額は **40円以上あける**（読み込み時に検査）。片側は1〜14人

→ 設計 2章の S3 の図、5.7（タッチ操作）、要件 3.1 P3（操作）・P4（画面）、要件 4章 U4

### 2.2 答え合わせ（S4）
- 決めたら、**取引の組を1組ずつ直線でつなぐ**。相手がいなかった人は薄くし、数字に線を引く
- 正解の値段を**青の点線**で重ねる
- 文は今まで通り（評価・成立 ○組・つり合いの値段・仕組みの一言）。仕組みの一言（2〜5日目）は、人数の変化が分かる文に直した

→ 設計 1.5、`ja.json` の `reasons` は直し済み

### 2.3 結果画面（S5）
- 日ごとの一言に「**正解を見る**」ボタン。押すと、その日の盤で正解の値段の組と、自分の値段（黒の点線）を見られる

→ 設計 1.7・2章の S5 の図

### 2.4 チュートリアル（新しい画面）
- タイトルに**専用ボタン「チュートリアル」**。「値付けを始める」はすぐ1日目へ（初回でも自動では出さない）。「遊び方」のリンク・説明文はなくした
- 左右5人の練習用の行列（`market.json` の `tutorial`。正解 1,000円・最大3組）で6つの手順：①値付け師の仕事 ②買いたい人 ③売りたい人 ④線を動かす ⑤組が一番多い値段で決める（外れたらもう一度）⑥本番は5日間・1日10秒
- **チュートリアルの中だけ**、動かしている間も組の線と「今 ○組」を出す（本番は決定 #2 のとおり隠す）
- 時間制限なし。「とばす」あり

→ 設計 1.1（流れ）・2章（画面の一覧に追加。M1「遊び方」は置き換え）
